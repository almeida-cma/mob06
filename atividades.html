🔊 Modelo – Controle de Volume

Enunciado: Crie uma página para controlar o volume de um aparelho de som. O usuário deverá escolher um valor de volume utilizando um controle deslizante. Ao alterar o valor, a página deverá apresentar o volume selecionado.

📋 Instruções

  • Crie a estrutura da página utilizando HTML.
  • Utilize um campo range para representar o volume.
  • Utilize CSS para organizar a apresentação.
  • Utilize JavaScript para capturar o valor escolhido.
  • Mostre o valor do volume na página.
  • Teste a aplicação no navegador.
  • Faça uma pequena alteração no exemplo.
💡 Dicas para chegar na solução:
  • Use <input type="range"> com os atributos min, max e value.
  • O evento onchange dispara quando o valor muda.
  • Para exibir o valor, use um elemento <p> com um id e altere o innerText.
  • No CSS, centralize o conteúdo com text-align: center no body.

✅ Sugestão de Resposta

HTML:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Controle de Volume</title>
    <link rel="stylesheet" href="styles.css">
</head>
<body>
    <div class="card">
        <h2>🔊 Controle de Volume</h2>
        <input type="range" id="volume" min="0" max="100" value="50"
               onchange="mostrarVolume()">
        <p id="saida">Volume: 50%</p>
    </div>
    <script src="script.js"></script>
</body>
</html>

CSS:

body {
    text-align: center;
    background: #f8fafc;
}
.card {
    background: white;
    max-width: 300px;
    margin: 30px auto;
    padding: 20px;
    border: 1px solid #999;
    border-radius: 12px;
}
input {
    width: 90%;
}
#saida {
    padding: 8px;
    background: #e0f2fe;
}

JavaScript:

function mostrarVolume() {
    let volume = document.getElementById("volume").value;
    document.getElementById("saida").innerText =
        "🔊 Volume: " + volume + "%";
}

1️⃣ Atividade 1 – Identificação

Enunciado: Crie uma página com um campo de texto para o usuário digitar seu nome. Ao clicar em "Testar", a página deve exibir o nome informado. O botão "Limpar" deve apagar o campo e a mensagem exibida.

📋 Instruções

  • Crie um campo de texto com id="nome".
  • Adicione dois botões: "Testar" e "Limpar".
  • Crie uma função mensagem() que exiba o valor digitado.
  • Crie uma função limpar() que apague o campo e a saída.
  • Estilize com um card centralizado e a saída em azul.
💡 Dicas para chegar na solução:
  • Use document.getElementById("nome").value para capturar o texto.
  • Use innerText para mostrar o resultado no parágrafo de saída.
  • Para limpar, defina .value = "" e chame a função mensagem() novamente.
  • Use onclick nos botões para chamar as funções.

2️⃣ Atividade 2 – Carrinho de Compras

Enunciado: Crie uma página que simule um carrinho de compras. O usuário informa a quantidade de fones de ouvido (R$ 29,00 cada) e a página calcula e exibe o total a pagar.

📋 Instruções

  • Monte a estrutura com um campo number para a quantidade.
  • Use o evento onchange para recalcular automaticamente.
  • Exiba o total formatado com vírgula no lugar do ponto.
  • Estilize o card com CSS.
  • Teste com diferentes quantidades (0 a 10).
💡 Dicas para chegar na solução:
  • Use parseFloat ou Number para converter o valor do input.
  • Para formatar o preço: (preco * qtd).toFixed(2).replace('.', ',').
  • Defina min="0" e max="10" no input.
  • Use id diferentes para o input e para a saída.

3️⃣ Atividade 3 – Controle de Estoque

Enunciado: Crie uma página que verifique se a quantidade solicitada de controles de videogame está disponível no estoque (3 unidades). Exiba uma mensagem de sucesso ou de estoque ultrapassado.

📋 Instruções

  • Mostre a quantidade disponível em estoque.
  • Use um campo number para o usuário informar a quantidade desejada.
  • Compare a quantidade solicitada com o estoque.
  • Exiba mensagens diferentes com cores distintas (verde/vermelho).
  • Use classes CSS para estilizar as mensagens.
💡 Dicas para chegar na solução:
  • Use if / else para verificar se a quantidade ultrapassa o estoque.
  • Altere className do elemento de saída para aplicar estilos diferentes.
  • Crie classes .ok e .no no CSS.
  • Use emojis ✅ e ❌ para reforçar a mensagem.

4️⃣ Atividade 4 – Formas de Pagamento

Enunciado: Crie uma página que simule a escolha da forma de pagamento para um total de R$ 100,00. PIX dá 5% de desconto, Cartão mantém o valor e Dinheiro dá 10% de desconto.

📋 Instruções

  • Use um elemento select com as opções PIX, Cartão e Dinheiro.
  • Capture a opção escolhida com o evento onchange.
  • Aplique os descontos conforme a opção.
  • Formate os valores com vírgula.
  • Estilize a saída com cores diferentes para cada forma de pagamento.
💡 Dicas para chegar na solução:
  • PIX: total * 0.95 | Cartão: total | Dinheiro: total * 0.90.
  • Use if / else if / else para tratar cada caso.
  • Altere className para aplicar cores diferentes.
  • Chame a função uma vez ao carregar a página para já mostrar o valor.

5️⃣ Atividade 5 – Endereço de Entrega

Enunciado: Crie uma página onde o usuário escolhe o local de entrega (Casa, Sítio ou Trabalho) usando botões de rádio. A página deve exibir uma mensagem informando onde o pedido será entregue.

📋 Instruções

  • Use input type="radio" com o mesmo name para agrupar.
  • Capture a opção selecionada com document.querySelector.
  • Exiba a mensagem correspondente ao endereço escolhido.
  • Use emojis para ilustrar cada opção.
  • Chame a função ao carregar a página.
💡 Dicas para chegar na solução:
  • Use 'input[name="endereco"]:checked' para pegar o selecionado.
  • Cada radio deve ter um value diferente.
  • Um dos radios deve ter o atributo checked.
  • Use if / else if / else para tratar as opções.

6️⃣ Atividade 6 – Cadastro de Cliente

Enunciado: Crie uma página para cadastrar um cliente com Nome, Idade e Cidade. Ao clicar em "Cadastrar", exiba os dados informados.

📋 Instruções

  • Crie campos de entrada para nome, idade e cidade.
  • Use um botão com onclick para chamar a função de cadastro.
  • Capture os valores com document.getElementById.
  • Exiba os dados concatenados em um parágrafo.
  • Estilize o formulário com CSS.
💡 Dicas para chegar na solução:
  • Use input type="text" para nome e cidade e type="number" para idade.
  • Use .value para pegar o conteúdo dos inputs.
  • Concatene as strings com +.
  • Use innerText para mostrar o resultado.

7️⃣ Atividade 7 – Cadastro com Select e Radio

Enunciado: Crie uma página de cadastro que utilize um campo de texto para o nome, um select para a cidade e botões de rádio para o tipo de cliente (Novo ou Cliente). Exiba os dados ao clicar em "Cadastrar".

📋 Instruções

  • Use <select> com opções de cidades.
  • Use input type="radio" com o mesmo name.
  • Capture o valor do select com .value.
  • Capture o radio selecionado com querySelector.
  • Exiba todos os dados concatenados.
💡 Dicas para chegar na solução:
  • O select retorna o value da opção escolhida.
  • Use 'input[name="tipo"]:checked' para pegar o radio marcado.
  • Um dos radios deve ter checked.
  • Estilize o select e os inputs com largura de 90%.

8️⃣ Atividade 8 – Pedido de Lanche com Checkbox

Enunciado: Crie uma página para pedido de lanche. O usuário informa o nome, escolhe o tamanho, a forma de pagamento e pode marcar adicionais (Fritas, Refrigerante, Sobremesa). Ao finalizar, exiba o resumo do pedido.

📋 Instruções

  • Use select para tamanho e radio para pagamento.
  • Use checkbox para os adicionais.
  • Verifique com .checked se cada adicional foi marcado.
  • Monte uma string com os adicionais selecionados.
  • Exiba o resumo completo do pedido.
💡 Dicas para chegar na solução:
  • Use if (document.getElementById("fritas").checked) para verificar cada checkbox.
  • Concatene os adicionais em uma variável string.
  • Use querySelector para pegar o radio de pagamento.
  • Monte a mensagem final com todos os dados.

9️⃣ Atividade 9 – Carrossel de Imagens

Enunciado: Crie uma galeria com 3 imagens que podem ser navegadas com botões de anterior e próximo. Ao trocar a imagem, exiba também um título correspondente.

📋 Instruções

  • Use uma variável para controlar o número da imagem atual.
  • Crie funções para avançar e retroceder.
  • Use if / else if / else para trocar a imagem e o título.
  • Garanta que o carrossel seja circular (volte ao início).
  • Estilize as imagens com largura fixa e bordas arredondadas.
💡 Dicas para chegar na solução:
  • Use imagem.src = "url" para trocar a imagem.
  • Controle o número com numero++ e numero--.
  • Se numero > 3, volte para 1; se numero < 1, vá para 3.
  • Use o site picsum.photos para imagens de exemplo.

🔟 Atividade 10 – Tema Claro / Escuro

Enunciado: Crie uma página que permita alternar entre tema claro e tema escuro. Ao clicar nos botões, a página deve mudar as cores e exibir uma mensagem indicando o tema atual.

📋 Instruções

  • Use dois botões: um para tema claro e outro para tema escuro.
  • Altere a classe do body para aplicar o tema.
  • Crie uma classe .escuro no CSS com cores escuras.
  • Atualize o texto de saída indicando o tema atual.
  • Use emojis ☀️ e 🌙 para ilustrar.
💡 Dicas para chegar na solução:
  • document.body.className = "escuro" aplica a classe ao body.
  • document.body.className = "" remove todas as classes.
  • No CSS, use body.escuro { ... } para estilos do tema escuro.
  • Altere também a cor do card no tema escuro.

📚 Glossário de Elementos, Propriedades e Comandos

🌐 HTML – Elementos

<!DOCTYPE html>
Declara que o documento é HTML5.
<html lang="pt-BR">
Elemento raiz, define o idioma da página.
<head>
Contém metadados, título e links para CSS.
<meta charset="UTF-8">
Define a codificação de caracteres.
<title>
Título exibido na aba do navegador.
<link rel="stylesheet" href="...">
Vincula um arquivo CSS externo.
<body>
Corpo visível da página.
<div>
Contêiner genérico para agrupar elementos.
<h1> a <h6>
Títulos de diferentes níveis.
<p>
Parágrafo de texto.
<label>
Rótulo descritivo para um campo de formulário.
<input type="text">
Campo de entrada de texto simples.
<input type="number">
Campo de entrada numérica.
<input type="range">
Controle deslizante para valores numéricos.
<input type="radio">
Botão de seleção única (agrupado por name).
<input type="checkbox">
Caixa de seleção múltipla.
<select> e <option>
Lista suspensa e suas opções.
<button>
Botão clicável.
<img>
Exibe uma imagem.
<strong>
Texto com ênfase forte (negrito).
<script src="...">
Vincula um arquivo JavaScript externo.
onclick
Evento disparado ao clicar em um elemento.
onchange
Evento disparado quando o valor de um campo muda.

🎨 CSS – Propriedades

color
Cor do texto.
background / background-color
Cor de fundo.
text-align
Alinhamento horizontal do texto (center, left, right).
font-size
Tamanho da fonte.
font-weight
Espessura da fonte (bold, normal).
max-width
Largura máxima do elemento.
margin
Espaçamento externo.
margin: 0 auto
Centraliza horizontalmente um bloco.
padding
Espaçamento interno.
border
Borda do elemento.
border-radius
Arredondamento dos cantos.
width / height
Largura e altura.
display: block
Faz o elemento ocupar a linha inteira.
object-fit: cover
Ajusta a imagem para preencher o contêiner.
box-shadow
Sombra ao redor do elemento.
transition
Suaviza mudanças de propriedades CSS.
classe (.)
Seletor para elementos com class="nome".
id (#)
Seletor para elemento com id="nome".

⚡ JavaScript – Comandos

document.getElementById("id")
Seleciona um elemento pelo seu id.
document.querySelector("seletor")
Seleciona o primeiro elemento que corresponde ao seletor CSS.
.value
Obtém ou define o valor de um campo de formulário.
.innerText
Obtém ou define o texto visível de um elemento.
.checked
Retorna true/false para radio ou checkbox.
.className
Obtém ou define a(s) classe(s) CSS de um elemento.
.src
Define o caminho da imagem em um <img>.
function nome() { }
Declara uma função.
let / const
Declara variáveis (let mutável, const imutável).
if / else if / else
Estruturas condicionais.
parseFloat() / Number()
Converte string para número decimal.
toFixed(2)
Formata número com 2 casas decimais.
.replace('.', ',')
Substitui ponto por vírgula.
numero++ / numero--
Incrementa ou decrementa uma variável numérica.
> / < / ===
Operadores de comparação.
+ (concatenação)
Une strings.
processarPagamento();
Chama uma função imediatamente ao carregar o script.
